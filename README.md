# BobsRentalsApplication_Moore

Katrina Moore
CPDM120

Description:
Bob's ski and snowboard rental is an application that manages snowboard and ski rentals. This application takes user input for the starting inventory, creates new customer rentals, returns rentals, views inventory, and creates an end-of-day report depending on the user's main menu choice.

Instructions to run the program:
To run the program, enter the starting inventory for skis and snowboards when prompted to, select a main menu option, and follow the prompts. Select End-Of-Day (4) when finished.

How I used the assigned classes:
I think the classes that I received were written very well, I believe I was able to execute all requirements for this assignment. The Customer class was used to store the customer name and ID. The Rental class was used to store information about an individual rental and to calculate estimated and final rental prices. The RentalEquipment was used for the specific rental equipment, rates, available inventory, and reducing/restoring inventory. The ski and snowboard classes inherit rentalequiptment and provide the appropriate prices. The rentalshop class manages the inventory, calculates the coupons and family discounts, and keeps track of daily rentals and revenue.

I do not believe any problems that I encountered were caused by the classes that I received. I did have a good amount of trouble figuring out how the classes worked together, but I eventually saw it.

Working with another programmer's code was more difficult than I expected. I had to learn the purpose of each class, its attributes, and methods before I could use them. This gave me experience with working with multiple classes and objects to create a whole application.
